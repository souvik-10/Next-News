# Next News

Next News is a full-stack MERN news platform featuring real-time news updates, interactive comments, article watchlist management, and client-side profile handling.

## Stack
- **Frontend**: React.js, TypeScript, Tailwind CSS, Axios, React Router
- **Backend**: Node.js, Express.js, TypeScript, JWT, Multer
- **Database**: MongoDB, Mongoose ORM
- **Real-Time API**: Express Server-Sent Events (SSE)

## Project Structure
```text
next-news/
├── client/     # React + TypeScript + Tailwind CSS frontend
└── server/     # Node.js + Express + TypeScript + Mongoose backend
```
